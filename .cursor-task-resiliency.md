## Implement the ADR's five items exactly:

1. **Shard watchdog**: SymbolShard consumer gets setUncaughtExceptionHandler logging
   "[clob-shard] DEAD symbolId=N", setting a volatile failed flag, then a System.exit hook
   that is INJECTABLE (a `Runnable exitAction` field defaulting to System::exit(2)) so tests
   can assert without killing the JVM. GatewayServer adds a 1Hz ScheduledExecutor sweep that
   logs shard liveness (keep it cheap; no allocation per tick beyond the log).
2. **Kill switch**: volatile halted in Gateway; submit() rejects SUBMITs with reason HALTED
   while halting, CANCELs unaffected. GatewayServer admin ops: POST /admin/halt, POST
   /admin/resume, POST /admin/cancelall (form/query param symbol= or all symbols when
   symbol=0 or "all"; reuse engine.cancel path per order id - you may need a shard-admin
   op that cancels ALL resting orders for a symbol; add CloudExchange.cancelAll(symbolId)).
   Responses are tiny JSON. Document localhost-only/no-auth in the handler comment.
3. **Durable journal + boot replay**: StripedEventJournal(dir) mode writing per-stripe
   journal/shard-N.log (buffered, flush every 500 events + shutdown hook + explicit
   flush() method), OrderEvent binary encoding via its existing fields (write your own
   DataOutputStream encoding if none exists). Add readAllEvents(stripe) for replay.
   GatewayServer startup: if -Dclob.journal=file (default memory), construct with dir
   (-Dclob.journal.dir default ./journal), replay via EventReplayer.replay into the
   exchange BEFORE accepting connections, log per-stripe counts + max eventId + gap check
   vs next ingress sequence (fail startup loudly on gap: "journal gap detected").
   runGateway runner must do the same order: replay → wire shards → serve.
4. **/health + /stats**: as specced (200/503). Wire LatencyRecorder: record at shard
   consumer completion using the ingressNano already carried on SequencedCommand;
   /stats reads recorder percentiles; counters: wsSessions open count, droppedSessions
   cumulative, msgsIn cumulative (AtomicLong, gateway receive path), ring depth per shard.
5. **Ingress bounds**: Gateway.validate adds maxNotional (priceTicks*qty <=
   Long.getLong("clob.maxNotional", 100_000_000L)), price ceiling
   1 <= priceTicks <= Long.getLong("clob.maxPrice", 1_000_000L), reject reasons NEW
   enum values (NOTIONAL_EXCEEDED, PRICE_OUT_OF_RANGE - follow existing reason style).
   Rate limit: token bucket per WsSession in GatewayServer.onClientText
   (clob.clientMsgRate default 200/s, burst 400): exceeded → send REJECT ack
   {"t":"reject","reason":"RATE_LIMITED"} + per-session counter; /stats exposes
